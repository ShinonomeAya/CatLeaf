## 2. 素材如何用于原生 App

| 对象 | 实施方式 | 任务 |
| --- | --- | --- |
| 品牌主标/组合标 | 使用定稿 SVG，保持透明表情和颜色，不裁原型图 | 页面任务 + T22 |
| 桌面/单色图标/启动屏 | 核对旧 android/ 已转换矢量后复用到新工程，使用系统启动机制 | N01、T24 |
| 40 个操作图标 | Lucide SVG 按页面需要转 VectorDrawable/Compose ImageVector，currentColor 映射主题 tint；原 React 组件列作来源对照 | D02 已交付，N01/T14 与各页面接入，T22 验收 |
| 空态插画 | 复用已交付独立 SVG；必要时转换平台资源，不增加一套插画 | 对应页面 + T22 |
| 按钮、导航、表单、卡片、正文 | Compose 控件与正文模板样式，文字可缩放、可读屏 | T08–T20 |
| 文章图片/封面/站点图标 | 真实内容数据与失败占位；不将原型样例图做默认文章 | T11/T12 |
| 手机外框、键盘、状态栏、分享面板 | 系统能力或仅原型展示 | 不切图、不硬画 |

不重新下载或复制第二套图标库。Lucide 版本/来源哈希和许可保持在素材索引；新客户端不依赖 lucide-react。纯矢量转换核对旋转、描边、evenodd 和透明性，不能直接把 SVG 当原生 drawable。

## 3. 平台检查

桌面前景/背景保持 108×108 dp 源画布、中心 66×66 dp 关键图形安全区和单色层。启动图标遵循既有无独立底板方案，不增加延迟网页开屏。Android 12+ 系统启动屏与最低支持 Android 10 分别验证。[自适应图标](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)、[启动屏](https://developer.android.com/develop/ui/views/launch/splash-screen)

旧素材包与截图是设计/旧工程证据，不能作为原生包安装验收。52 个 SVG 未因框架变化重绘；既有 zip 保留为当时素材快照，最新工程接入规则以工作区文档为准。
