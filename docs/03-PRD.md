## 1. 产品目标

让个人用户从手机桌面直接进入订阅阅读，在 App 内完成“看更新 → 读文章 → 翻译/摘要 → 收藏”，日常无需先打开浏览器查找网站。

主用户：一位 Android 用户。常见场景：通勤时快速浏览；阅读外语文章；晚上回看某个订阅源当天的内容；无网络时继续看已保存文章。

## 2. 首版成功标准

- 新装无需实例或AI即可开始使用，可跳过引导进入本机空态；以后从图标直接回阅读。老用户升级继续原实例，无需重新配置。
- 能独立添加订阅，打开文章，保存已读和收藏，关闭进程后状态仍在。
- 无 AI 配置也能正常阅读；有配置时能翻译并生成有来源的日摘要。
- 飞行模式冷启动能显示缓存列表和已保存的正文文本；图片未缓存时显示占位，不能无限加载。
- AI、单个 RSS 源或全文提取失败时，已有内容仍可阅读。

以上是验收目标，不是本轮测得的性能或成功率。

## 4. 信息架构与交互

底部三个入口：**阅读 / 收藏 / 设置**。阅读页顶部提供当前源选择与日期筛选；订阅管理从源选择面板进入。避免在小屏幕上同时展开左右两个侧栏。

| 页面 | 主要内容 | 主要动作 |
| --- | --- | --- |
| 首次引导 | 欢迎、五个未勾选首选源 | 开始阅读、选择订阅、跳过、手动添加、导入OPML、浏览更多 |
| 发现订阅源 | 精选/全部、12分类、搜索、源说明与状态 | 查看详情、预填添加、选择个人分组 |
| 使用方式 | 本机/自有实例、收益与数据保留说明 | 连接/切换、复制已下载数据到本机 |
| 阅读列表 | 当前源、日期、未读筛选、上次更新时间、文章列表 | 下拉刷新、切源、打开详情、生成本日摘要 |
| 订阅管理 | 分组、RSS URL、名称、源状态 | 新增/修改/删除，导入/导出 OPML |
| 文章详情 | 标题、作者、来源、时间、正文、已读与收藏 | 翻译、查看全文、分享、原网页 |
| 日摘要 | 日期、范围、文章数、正文、来源列表、生成时间 | 查看原文、复用已有摘要、确认后重新生成 |
| 收藏 | 已收藏文章、保存状态 | 打开、取消收藏、导出链接 |
| 设置 | 主题/字号、AI、实例、存储、导出恢复、版本/许可 | 测试连接、清缓存、管理密钥 |

文章阅读使用受控正文视图；用户主动选择“原网页”时交给系统浏览器能力（Custom Tabs或外部浏览器），不在正文WebView直接载入外站，外部网页不拥有App原生桥接权限。

Android 返回键顺序：关闭弹层 → 返回上层页面 → 阅读根页按系统行为退出。详情返回必须还原当前源、日期和滚动位置。

### 关键流程

1. 首次使用：安装→欢迎→选择五源/更多源、手动添加或OPML→本机阅读；各阶段可跳过，不配置实例或AI。
2. 日常阅读：图标打开 → 立即展示缓存 → 在线更新所选源 → 查看文章 → 标为已读/收藏 → 返回原位置。
3. 翻译：进入文章 → 点击翻译 → 未配置时引导设置 → 展示处理状态 → 成功保存；失败可手动重试，原文持续可用。
4. 日摘要：选源与日期 → 展示文章数与范围 → 确认生成 → 展示摘要和对应文章 → 下次优先读取缓存。

## 5. 业务规则

### 5.1 订阅、更新和历史

- 首版只接受可访问的 HTTPS RSS/Atom；导入失败给出条目原因，不把 HTML 页面静默当作 RSS。
- URL 去重采用标准 URL 解析与保守规范化，不随意删除可能影响内容的查询参数。文章身份优先匹配“实例 + 源 + GUID”，再匹配原文链接；不能仅凭标题合并。两者都缺失的条目跳过并显示数量，详见接口契约。
- 订阅编辑只修改名称与分组；更换 RSS URL 作为新增源处理，防止旧文章身份错绑。
- 单源失败不能清空旧数据；保留上次成功时间和重试入口。
- 删除订阅需确认；保留已收藏文章的本地快照和来源链接，普通缓存可清理。重复导入不得重复新增已有源。
- OPML 多级分组先保留为路径名称映射到一级分组，预览显示转换结果；导出保留原 URL，不导出访问密钥。
- 2026-10-14批准发布反馈增量：OPML保留2MiB读取预算，支持UTF-8/BOM与明确UTF-16，最多解析2000条、每批导入200条并可继续后续批次；结果保留验证失败原因并可直接重试已保存源。新增同页AI概览、重点、段落解释与本文问答、主题日摘要，复用用户自配供应商及手动请求／缓存／来源定位，不默认后台生成。具体边界和验收见[发布反馈与AI辅助阅读实施计划](../tasks/发布反馈与AI辅助阅读实施计划.md)，本条批准不代表已经实现。
- RSS 源可能只保留最近若干条；App 长期未打开时，无法保证补回所有历史。界面显示“已获取内容”，不承诺完整归档。

### 5.2 阅读、收藏和离线

- 进入已成功显示正文的详情后标为已读，允许手动设回未读。
- 已读/收藏等权威状态持久化到本地数据库；列表可由网络更新，但不能覆盖用户状态。
- 普通文本缓存首版上限 2,000 篇或 100 MiB，正文与普通 AI 缓存计入，先到者触发按最近访问淘汰；该数值是工程预算，若技术验证需要调整，应记录原因并同步契约。
- 收藏不参与普通自动淘汰；保存到磁盘失败时明确告知“尚未离线保存”，不得显示成功。容量不足时保留已有收藏并提示处理。
- 普通缓存/收藏仍只保证已取得的正文文本；新增主动单篇图文保存按§11反馈实际结果，不承诺未下载图片、音视频或未提取全文离线可用。
- 清除普通缓存不清除订阅、已读、收藏和密钥；恢复出厂配置另设有范围说明的确认动作。
- 导出本地状态包含源、文章身份、已读与收藏链接；可恢复这些标记，不承诺恢复未导出的正文。卸载后本地数据可能丢失，提供导出入口。导出不含实例密钥和 AI Key，但 RSS URL 自带的订阅 token 会随 URL 保留，导出前提示文件需私密保存。

### 5.3 AI 和内容质量

- 阅读功能不依赖 AI。用户主动触发后才向其选择的供应商发送对应文本；设置处显示接收方、模型与用途。
- 首版以一个实际可用的 OpenAI 兼容供应商/模型验收；“兼容”不等于所有端点和模型一定可用，提供一次手动连接测试。
- 翻译输入为当前正文的纯文本块，编号后一次请求，输出不允许默默变成摘要。首版单次上限 20,000 字符，并受具体模型更小限制约束；超限时说明原因，允许继续阅读原文，长文分批请求与选段交互放 P1。2026-10-10 用户确认：译文显示在对应原文下，图片与链接保留；切换显示不再次请求。旧版整篇缓存保留并明确标识，主动重新翻译才生成双语结果，不自动付费升级。
- 日摘要范围为“当前源或全部订阅、所选日期、用户勾选的本机可用文章集合”；显示数量与是否仅基于摘要字段。全部订阅仅包含活动范围仍订阅的源；候选按所选日期从数据库获取，不受阅读列表200篇首批窗口限制。不自动抓取未保存的历史，不能把部分数据生成的结果叫“全部资讯日报”。
- 日期按设备本地时区计算 00:00 至次日 00:00；缺失/无效发布时间的文章进入“日期未知”，不自动纳入某一天。
- 每次摘要最多30篇且正文输入合计不超过30,000字符；以具体模型实际限制为更小边界。范围预览提供显式「清空勾选」，便于从零自选，或逐篇取消后再生成；不能后台静默截断。调整勾选集合立即使旧集合的在途缓存回包失效，只重新匹配新集合，不自动生成。
- 摘要应输出可映射到输入文章的来源编号，App 只将有效编号映射成真实链接。无有效来源的结果标记为不完整，不伪造来源。
- AI 结果注明“AI 生成”，不补造活动时间、数字、结论。原文内容视作待处理数据，不作为执行应用操作的指令。
- 缓存按任务、文章内容指纹/摘要文章集合、模型、语言和提示版本区分。同样输入重复打开复用缓存；修改模型或重新生成需要用户触发。
- 401/403 提示密钥或权限；429 提示限流/额度；超时/网络错误保留原文与旧结果。没有成功结果不得写成功缓存；不自动无限重试付费请求。
- 用户取消/离开页面后停止继续呈现该任务为进行中；提示供应商已接受的请求可能仍产生费用，不承诺取消即免计费。

### 5.4 AI解读（2026-10-14已批准增量）

文章顶栏直接显示独立AI SVG图标入口，在当前详情上打开概览／解释段落／问本文面板，原文与双语阅读入口保留。更窄屏时将已读状态文字动作移至更多菜单，状态操作仍可达。无键盘时面板无AI结果约52%屏高，有结果约78%；键盘出现后按扣除IME的可用高度计算相同比例，至少360dp且不超过可用高度。局部关闭面板拖拽，由内容列表独占滚动，关闭／遮罩／系统返回保留，键盘与大字仍可操作。

解释可用原生段落列表，亦可长按当前原文选择不超过2000字符，经原生文本菜单「AI解读」打开解释面板并可切问本文；只接受唯一可靠匹配一个当前原文段落的选文，多段／歧义／失配提示使用段落选择。译文不给选文AI入口，文章／正文／范围已变化的旧意图直接失效。选文入口不自动发请求，不用JS、桥接或剪贴板读取选区。没有可引用文字时不给假答案；只有摘要时明确仅依据摘要，生成不自动获取全文。

标题与文字段落合计最多20,000字符，编号输入JSON最多40,000字符；问题最多500字符。图片和代码块不进入本批文本任务，不做OCR、长文分批或全网搜索。概览给出重点；每个事实答案／重点只引用当前输入中存在的段落。本文未提供的信息明确提示；术语背景解释独立标注「不是本文事实」。编号有效只证明链接可定位，答案内容仍需用户核对。

U06／U07续修统一总入口与面板名称为「AI解读」，覆盖概览／解释／问本文，旧0.1.26的「AI辅助」名称保留为历史。每个答案／重点的依据默认只显示一行「查看依据（N处）」，展开才显示「标题／第N段」短标签，全部引用ID和原文定位保留；收展不请求AI。新请求提示只选足够支撑事实的最少必要依据，通常1至3段，但不设置解析硬上限、不截断旧结果。v2结果格式及缓存键保持，旧完整缓存可按新样式显示，不自动重算。

打开任务先匹配本地缓存，不自动发请求；生成／重新生成由用户点击并提示接收方、模型与可能费用。任务、问题或选段／选文、正文指纹、文章／活动范围及模型改变后重新匹配；相关任务缓存键包含选文哈希，引用仍使用原段落ID。旧在途响应不得覆盖后来打开的内容。失败、截断、无效引用或写盘失败保留原文及旧完整结果，不写成功缓存。

AI设置提供DeepSeek快捷填入`https://api.deepseek.com`与`deepseek-flash`，仅填地址／模型，不自动保存或测试。Key由用户配置并绑定供应商HTTPS origin，切换供应商不得复用另一origin的Key。兼容其他OpenAI端点的原手动配置保持；本批没有多账号登录或自动供应商切换。

## 10. 已批准增量范围（2026-09-25）

### 10.1 本机与实例

本机可离线管理订阅，在线直接抓公开HTTPS RSS/Atom；失败保留源并标状态。实例模式沿用受保护服务端目录与抓取；同源去重、收藏保护、AI限额等共同规则不变。设置中切换使用方式，保留非活动范围，不合并两个列表。无网络也能返回本机或阅读曾连接实例的缓存。

老用户首次升级继续原范围，不清库、不重放欢迎引导。连接新实例必须成功获取目录并安全保存后再切换；失败留在原范围。复制到本机是显式、本机事务操作：预览选源与已下载文章/阅读状态，原实例不删除，不复制凭据/AI缓存，不后台拉取所有远端历史。详细合并与不足空间规则见契约§8。向实例导入用现有OPML或状态文件预览，不创建双向同步。

### 10.2 引导、目录与分类

首选固定为少数派、爱范儿、IT之家、阮一峰的网络日志、The Verge，均初始未选；选0项主按钮禁用，跳过始终可用。只有确认订阅才发请求，重复进入不重复新增；部分失败显示实际结果并可继续阅读。欢迎页导入OPML、手动添加/更多目录可替代引导路径。

完整目录基于top-rss-list固定快照340条候选，加首选五源缺项，全量处置而不是只精选少数项。最终收录数量以去重/逐条核验为准；不可把340写成可用数。分类固定12类：科技数码、编程技术、商业财经、新闻时事、效率工具、设计创意、文化阅读、生活方式、科学教育、游戏娱乐、个人博客、其他。一源一个主分类、少量标签和语言；精选/全部是视图。目录分类只建议个人分组，更新不得移动用户订阅。

发现入口在订阅管理、无源空态及引导，根导航仍为阅读/收藏/设置。本地搜索名称、域名、简述、标签；匹配与当前分类取交集，精选按固定ID列表显示，跨全库搜索用明确“在全部中搜索”操作。2026-10-09用户批准在原五源后追加“橘鸦AI早报”（https://daily.juya.uk/rss.xml）；首次引导仍只展示原五源，不自动订阅。离线可浏览内置清单，不联网拉全目录文章；目录随App更新，不建运营平台。

2026-10-09目录HTTPS补充：可收录和需配置项的实际订阅地址均须为无凭据HTTPS。旧HTTP地址只在台账保留；公开验证HTTPS替代且原生解析成功后才更新目录，保留稳定ID。超时、证书错误或不合法RSS列为待复验，不发布可添加项；不放宽客户端HTTPS规则，不批量修改用户已有订阅。

原站与第三方生成源标识来源；需配置条目独立筛选并解释，失效/待核验项不冒充可用推荐。点击添加打开预填表单确认分组，已订阅状态按活动范围判断；同名不同频道不误合并。上限仍为每个活动范围200订阅，目录不占名额；全文/缓存/AI/备份限额不变。

### 10.3 筛选与提交反馈

日期组“全部、今天、指定日期、未知日期”，另一个独立“仅未读”开关可组合。全部只清日期限制，未读开关保持可见；选定日期显示具体日期，取消选择不改条件。“清除筛选”同时归全部与未读关闭。范围提示“已加载N篇”，不把全部理解为全站完整历史。

2026-10-09用户选定阅读首页C「紧凑标签」：日期入口显示“全部日期”或当前条件，下拉面板仍按全部日期→今天→指定日期→未知日期选择；“仅未读”为独立可选标签，与日期组合。清除同时重置两者、结果数仅统计已加载筛选结果。搜索页日期组与多开关保持原组织，不因首页选C改变业务。

添加/保存按钮的文案相对整按钮居中，转圈不挤移文字，系统大字可增高。提交前校验HTTPS；不静默降TLS。显示真实阶段：正在添加、正在验证、已添加并验证、已添加但验证失败、提交结果待确认。失败不丢输入或已登记源，重试先核对，禁止重复请求造成重复源。

## 11. 文章搜索与单篇图文离线（已确认）

### 11.1 搜索范围与交互

发现页的订阅源搜索保持不变。本节是独立的文章搜索：阅读页和收藏页增加搜索入口，不增加底部栏目。阅读入口默认当前源、当前日期与未读条件，均显示为可清除条件；切“全部订阅”搜索当前本机/实例范围内所有已保存文章，不限列表已加载的200条。收藏入口默认“仅收藏”，可关闭；不跨使用方式查其他实例，不联网搜索或自动拉远端历史。

分两批交付：先标题/摘要，后增加“搜索正文”开关（默认关闭）。全文只包含已经保存在设备的原文，不搜索AI译文、摘要结果、图片文字或未保存内容；只有书签仍可命中标题。搜索不改变已读，打开正文后沿既有已读规则。结果按发布时间倒序、未知日期最后、稳定ID破同序；显示匹配片段和命中位置，返回恢复关键词/筛选/结果位置。清除筛选不清关键词；清空关键词显示输入引导，不列出全部正文。错误不能显示为零结果。

### 11.2 主动保存离线

从详情页更多菜单“保存离线”进入，不再挤满底部工具栏。默认保存当前已取得正文并勾选“包含正文图片”（包括封面，按URL去重）；可关闭图片仅保存文字。只有摘要/书签时明确“当前没有可保存正文”，可返回“获取全文”，不自动抓原网页或调用AI，不把摘要当完整正文。

收藏与主动保存独立；收藏仍保护文本，但不自动下载图片。主动保存使用独立保护与容量预算，清普通缓存、取消收藏或删除订阅都不能删除离线副本。保存到App私有目录供猫页阅读，不导出PDF/HTML或写入系统下载目录。无图正文可以完成文字保存；“所选内容已保存”只代表本次选择，不能声称原网页全部内容已归档。

状态区分等待/保存中、仅正文已保存、所选图文已保存、正文已保存但图片未齐、未成功、已中断。显示图片实际完成数，失败可仅重试未保存图片。取消停止后续请求，已落盘正文和图片保留；进程终止后标中断，不假成功、不自动续传。单篇手动任务顺序执行，不承诺后台常驻；本轮无批量/自动下载。

### 11.3 管理与边界

设置→存储→离线内容，列当前范围保存项、真实状态与占用；所有范围共用300MiB离线保存预算，显示总占用和当前范围占用。预算不含原普通缓存100MiB和既有受保护收藏文本；达到上限停止新增/补图并提示管理，不自动淘汰手动保存。单篇最多20MiB、最多50个唯一图片；单图上限10MiB（10,485,760 bytes，2026-09-30用户最终确认，替代先前5MiB方案），任何超限均标未保存及原因，不算完整。以上为可落地初始工程限额，调整需同步契约和验收。

在线正文图片、列表缩略图、单篇离线保存与失败重试共用上述单图上限；保留原解码检查、缩略图采样和请求安全边界。此项按[IP01实施](../tasks/本机模式与发现源实施计划.md)，当前code6安装包仍为2MiB，改后验收前不能宣称已生效。

移除副本先确认，只删除该离线包，不取消收藏/已读或删除订阅；若它是唯一正文副本且已收藏，先成功保留文本再删除，失败中止。空间不足、图片失效或受限时仍可读成功保存的正文。新快照成功前旧副本继续可用；没有手动更新就不后台覆盖。

状态v2备份不包含离线包、图片或“已下载成功”状态；恢复后如实显示未下载。复制到本机沿L05只复制既定正文/状态，不复制离线图片包或自动继承已下载标记，预览须说明；原范围离线包保留。删除App或重置设备数据会删除离线包，帮助需说明。
