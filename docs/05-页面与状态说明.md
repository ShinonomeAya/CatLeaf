## 1. 导航与共同规则

根页三个入口：**阅读、收藏、设置**。详情与日摘要为二级页面，隐藏底部导航以留出阅读空间。订阅选择用底部面板，订阅管理由面板进入。源编辑、导入预览和数据管理不塞入一个超长弹窗。

阅读结构：顶部当前源及选择、日摘要入口与刷新；下方日期组和独立仅未读开关、刷新状态；中间文章行；底部三个入口。详情标题/元信息/封面与正文共同滚动，只有紧凑工具栏常驻；不恢复旧固定大标题。

返回顺序：关闭最上层弹窗或面板 → 返回二级页面的原入口及位置 → 阅读根页遵循 Android 返回行为。使用现有路由/状态机制加最少导航逻辑，不先引入大型路由状态框架。保存文章 ID 和滚动锚点，避免仅凭易变化的列表下标恢复。

| 共同状态 | 界面规则 |
| --- | --- |
| 首次加载无缓存 | 简单骨架或进度说明；超过请求超时显示重试，不永久转圈 |
| 已有缓存、正在刷新 | 旧内容持续可操作，顶部小型刷新状态 |
| 离线 | 显示“离线，正在显示已保存内容”；隐藏虚假实时更新时间；禁用依赖网络的动作并说明原因 |
| 空数据 | 按原因显示“还没有订阅”“这个日期没有已获取文章”“没有符合筛选的内容”；给对应操作 |
| 部分失败 | 错误局限在当前源/条目/操作；不清空全局内容 |
| 敏感表单 | 默认隐藏密钥，可主动短暂查看；输入不进入普通自动保存、日志或导出 |
| 操作完成 | 显示真实保存/请求结果；网络成功但本地写盘失败不能提示“已离线保存” |

主要触摸区域至少 48 dp，底部/顶部避让系统区域，弹出键盘仍能看到提交按钮。重要错误同时用文字说明；图标加可读名称。正文大字号允许换行，按钮不被固定高度裁掉。

## 2. P01 首次引导 / 可选实例

全新安装默认本机，欢迎页→五源选择，均可跳过，不进入强制实例配置。老用户升级保留原实例与缓存，不重复引导。实例连接为设置中的可选二级页面，以下表仅用于该连接流程。

| 项目 | 说明 |
| --- | --- |
| 字段 | 实例 HTTPS 地址、个人访问密钥；附短说明“由你的个人后端提供” |
| 主操作 | “连接并切换”；校验地址→获取受保护完整订阅列表→安全保存→切换，保留本机/旧实例数据 |
| 网络失败 | 区分地址不可达、TLS/网络问题、未授权、后端未配置；保留当前输入，可重试 |
| 无实例 | 本机完整基础阅读可用；帮助在设置可达，不默认连接任何作者站点 |
| 已有实例离线 | 允许进入该实例的本地缓存，明确尚未验证连接 |
| 切换实例 | 显示目标 origin 与“阅读数据按实例隔离”；新连接失败不替换当前实例；成功后切换 namespace |

AI 配置在设置页，首次连接不要求填写。密钥失效弹出修复入口，但本地已保存内容仍可读。域名变化视为新实例，通过状态备份显式迁移。

## 3. P02 阅读列表与源选择

使用当前数据范围的上次源；没有则选首个有效源。日期组固定“全部、今天、指定日期、未知日期”，下方独立“仅未读”开关。全部仅取消日期条件，未读保持；“清除筛选”重置两者。选日期后显示实际日期，取消选择不改状态。日摘要仅有效日期可用，其入口始终可找；全部/未知点击时先引导选日期。

2026-10-09阅读首页局部以用户选定C稿覆盖上段控件形式：日期标签展开四项面板，“仅未读”独立勾选标签；下方显示本机已加载结果数和清除操作。指定日期先关闭范围面板，再打开既有日期选择器，取消保留旧条件；系统返回关闭当前面板/选择器，保留列表。原单源、筛选语义、锚点及日摘要范围不变。对应01/08/21/32，搜索35/36多开关不同时替换。

卡片显示标题、来源、时间、简短摘要、已读/收藏状态；图片可选，失败不影响文字。点击打开详情；列表不自动翻译或分类。缓存恢复后显示上次成功抓取时间；源有错误时显示在源名旁。

下拉刷新当前源；显示“已加载N篇”。本机只追加本地保存页，结束说明已显示本机保存内容；实例可按页加载服务端历史，失败保留已有页。日期只筛已加载集合，不宣称全站没有内容。

源面板按一级分组列源名，可见“管理订阅”入口。历史 articleCount 如果展示要标“已存历史”，不能当作未读数。未读数只统计本地实际已加载文章，并标清范围。

## 4. P03 订阅管理与 OPML

管理页提供源名称、分组、URL、抓取状态、最近成功时间。新增填写 HTTPS RSS URL，可选名称与分组；无名称时使用抓取标题，再无标题显示主机名。现有源只允许改名称和分组；URL 字段只读并说明换地址需新建。

新增先显示登记阶段再验证，分别显示“已添加并验证”“已添加，验证失败”“已保存，联网后验证”或“提交结果待确认”；登记失败保留表单输入。验证失败条目保留可重试。本机删除确认“移除此设备订阅，收藏保留”；实例删除确认“删除云端订阅与历史，本机收藏保留”，失败不假删除。

OPML流程：选择文件→有界本地解析→预览→开始本批导入→逐项结果。支持UTF-8/BOM与明确字节序UTF-16，文件2MiB、解析2000条、每批导入200条。预览列名称、规范化分组、URL、重复／无效原因及勾选项，默认仅勾选当前批有效且未存在的源；其它有效项标为后续批次。已处理项不能再勾选，用户本批未勾选项与未处理的后续项分开显示；结果页可继续下一批并保留前批结果，不提高每个活动范围200订阅上限。只读出问题的XML不触发写入，HTML／XPath等抓取配置不是标准RSS订阅，明确提示不支持而非静默当RSS。

开始后显示X/Y；取消说明「已导入条目会保留」。结果区分已新增并验证、已保存但验证失败及其脱敏原因、失败、待确认、重复／跳过与待后续批次；结果页直接重试未解决项。已保存但验证失败复用原feedId验证，不重复新增。新增请求超时显示「结果待确认」，先读完整源列表按规范化URL核对，再决定关联已有源或沿幂等新增路径重试，不能断言服务器未写入。重新选文件或切活动范围后，旧任务不得回写新预览。

导出说明“仅订阅和分组，不含已读、收藏或正文”；含私有订阅URL时提醒私密保存。发现目录与目录关键词搜索见§10，文章搜索见§11；不做社交广场和排序拖拽。

## 5. P04 文章详情

首屏优先展示 RSS 正文；没有正文则展示摘要和“获取全文”。标题、来源、作者（有则显示）、设备本地时间、原文链接始终可找。没有有效日期显示“发布时间未知”，没有原文链接则禁用分享原链接/原网页，不能合成假地址。

| 动作/状态 | 行为 |
| --- | --- |
| 正文成功显示 | 标为已读；手动“设为未读”后保持用户选择，不能同次渲染立即改回已读 |
| 获取全文 | 只在用户点击后发生；原内容持续可读；成功替换并标“提取全文”；失败显示原因并保留 RSS 内容 |
| 收藏 | 本地事务成功才变实心图标；提示“已收藏，已保存文本可离线”；若只有链接无正文，明确只是书签 |
| 取消收藏 | 可直接操作并提供短时撤销；不立即清空正在看的正文 |
| 原网页 | 主动打开官方 Browser 提供的隔离浏览页面；不在可用原生桥接的主页面加载 |
| 分享 | 系统分享标题与安全原文链接，不携带实例 API 地址或任何 Key |
| 图片/音视频 | 图片失败/离线显示占位与替代说明；音视频提供原网页入口，不承诺缓存 |
| 返回 | 恢复来源页、筛选、列表锚点；从收藏进入则回收藏 |

翻译成功后显示“原文 / 双语对照”切换及 AI 标识，默认在对应原文下显示中文，保留原图文与底部翻译按钮。已有旧 v1 缓存时第二项标为“旧版译文”，继续显示旧整篇结果并提示主动重新翻译可生成双语且可能计费；不自动请求。请求时原文可继续阅读，按钮显示进行中，禁止重复提交；失败、截断、段落对应错误和取消都不覆盖已有完整译文。超 20,000 字符显示“正文超过首版翻译上限，可继续阅读原文”，不临时加入选段编辑器。正文/范围改变后重新匹配缓存，迟到响应不能覆盖新内容。

### 5.1 AI解读面板（2026-10-14增量）

详情顶栏用独立AI SVG图标打开「AI解读」，仍留在当前文章，原文／双语标签和翻译入口保持。图标触摸区至少48dp；更窄屏将已读状态文字动作移至更多菜单，状态操作仍可达。面板顶部为标题与关闭、概览／解释段落／问本文标签；无键盘时无结果约52%屏高，有结果约78%；键盘出现后按扣除IME的可用高度计算相同比例，至少360dp且不超过可用高度。面板自身不接受拖拽，由内容列表独占滚动，底部为唯一手动主操作；关闭、点遮罩和系统返回均回到原文章与读位。

内容先说明当前输入是RSS正文／提取全文／离线副本／仅摘要、字符数与模型，提示新请求会发送标题及文字段落、可能产生费用。打开及换任务优先读匹配缓存，不自动请求；没有可分析文字或超预算时给出原因。解释任务用原生标题／段落列表选择并显示选段，可换段；问本文提供最多500字符输入。忙碌时禁用任务／输入和重复提交，关闭或切文章／范围后旧结果不能覆盖新内容。

长按当前原文选择文字时，原生文本菜单提供「AI解读」入口；最多2000字符且必须可靠匹配同一当前原文段落。成功打开解释面板显示选文，可切到问本文，后续生成仍需手动点击；选文不同重新匹配缓存。原文多段或歧义／失配时给出原因及段落选择入口；译文不装选文AI入口，文章／正文／范围已变化的旧意图直接失效，不打开任务。原有复制／文字选择能力保留，不新增剪贴板读取。

结果标注「AI解读·已缓存／刚刚生成」。每个答案与重点的依据默认折叠为单行「查看依据（N处）」，展开显示「标题／第N段」短标签，并可「收起依据」；完整读屏名称为查看原文标题／原文段落N，48dp可点。展开、收起不请求AI，保留全部ID及每条事实的对应来源；点有效引用关闭面板、回到当前原文并定位标题／段落，不跳转模型链接。本文未提供时清楚显示「本文未提供」，不展示虚构引用；背景解释单独注明「不是本文事实」。重新生成明确会再次请求；错误、截断、无效引用或保存失败保留旧完整结果。新请求仅软性建议通常1至3个必要依据，旧v2缓存不截断、不自动重算；引用存在不保证事实正确，显示核对原文提示。

## 6. P05 日摘要

分「范围预览」和「结果」两步。范围为当前单源或全部订阅，显示范围名、日期、时区、本机该日候选数、勾选数量、总字符数，每篇标正文／仅摘要。候选按所选日期从当前范围已保存文章取得，全部订阅排除已删源，不受阅读页已加载200篇窗口限制；不自动拉未下载历史。勾选统计处提供「清空勾选」，用户可先清空再自选，或逐篇取消以满足30篇、30,000字符限制；无有效输入时不能提交，超限不能静默截断。清空与逐篇调整后，旧集合在途缓存回包不得切回旧结果，仅重新匹配当前选择，不自动生成。显示仅依据本机已有内容、可能不包含该日全部文章。

点击“生成摘要”前显示供应商/模型和会发送已选文章内容；不要求每篇重复确认。已有完全匹配缓存优先打开；“重新生成”提示会再次请求。页面切换期间结果只归属原任务，不能写到用户后来切换的源/日期。

结果按「日期／范围与模型→简短概览→主题与要点→原文来源」组织，显示生成时间。同事件合并但保留多篇来源，来源按钮可换行。继续手动生成，打开旧完整缓存不自动补主题或重新请求。点击来源进入已缓存文章；无法离线打开时给出原因及原链接。任何无效编号不能变成真实链接。「结果不完整，来源待核对」与正常成功清楚区分。新增文章只提示范围变化，不自动再次调用。

## 7. P06 收藏

按收藏时间倒序。每项展示标题、来源、收藏日期及“文本已保存 / 仅书签 / 来源已删除”。进入前两者行为有区别：只有书签时离线说明没有正文，在线允许重新获取；不能让用户看到空白详情。

收藏空态复用已有浅/深empty-reading SVG的原生drawable，按「插画→还没有收藏→在文章详情点击收藏即可保留→去阅读主按钮」在可用内容区成组居中；大字/窄屏可滚动，装饰图不重复朗读。读取错误显示重试而非假空态。导出链接与状态备份入口通往同一数据管理页，避免重复实现导出。导出链接可从状态文件/系统分享得到；若提供单独文件，采用简单 UTF-8 文本（标题和 URL），不是新备份格式。

## 8. P07 设置与数据管理

| 分组 | 内容 | 关键状态 |
| --- | --- | --- |
| 阅读 | 跟随系统/浅色/深色；正文小/标准/大/特大对应 16/18/20/22，默认 18；单位映射按设计规范 | 即时预览并保存；系统字体缩放继续生效 |

| 重置 | 重置此设备数据 | 单独危险操作；二次确认；不删除云端订阅 |
| 关于 | App 版本、构建来源、上游与依赖许可 | 保留 MIT 版权/许可；不保留原作者品牌冒充官方 App |

状态恢复预览显示来源本机/实例、当前目标、源数/已读/收藏数、拟新增源与无效项；跨范围需明确确认。目标本机用本地事务；目标实例分别显示远端订阅与本地写入结果。兼容旧状态v1，新导出v2并解释旧客户端兼容性；不把正文称为已备份。
