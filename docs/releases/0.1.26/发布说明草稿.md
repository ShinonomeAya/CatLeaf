# 0.1.26 测试候选版

AI辅助阅读现在直接显示在文章顶栏。没有结果时面板约占半屏，保留正文方便提问；生成结果后扩大，内容独立滚动。修正快速滑动时面板抽搐、段落卡片文字碰边和键盘遮挡问题。

长按原文后可点击文字菜单「AI辅助」，将选文带入解释或问本文。打开面板不会请求AI，生成仍由用户主动点击；原文复制、全选和双语入口保持。选文仅适用于可唯一匹配一个当前原文段落的文字，歧义或跨段时可改用段落列表。

最终源码通过单元、lint及Debug／Release构建；Android10隔离相关回归和八组界面矩阵通过。同签名Release在Android16手机保数据复测快速滑动、半屏、选文和键盘返回，安装包哈希一致。手机没有发起AI请求，选文任务的真实答案及更多OEM兼容仍待验证。
