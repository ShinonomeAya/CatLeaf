# 0.1.28 公开测试版（Pre-release）

已按用户授权发布：[下载与发布说明](https://github.com/ShinonomeAya/CatLeaf/releases/tag/v0.1.28)。该文件沿用候选期文件名，以下为实际公开版记录；包身份与验证范围见[release.json](release.json)。

这次更新改进了 AI 辅助阅读和 OPML 导入体验，继续以 **Pre-release** 形式提供试用。

- **AI 解读**：文章顶栏新增直接入口，支持概览与重点、段落解释、问本文；也可以长按选中可靠的单段原文文字，从系统菜单进入 AI 解读。所有生成均由你手动触发，打开面板或查看缓存不会自动请求 AI。
- **依据更清爽**：答案默认显示「查看依据（N处）」，展开后可查看全部标题／段落引用并跳回原文，不因折叠而丢失依据。AI 答案仍需结合原文核对。
- **OPML 更好恢复**：支持最多 2000 项的 OPML 文件解析，每批处理最多 200 项，可继续处理后续条目；失败原因保留，已保存的订阅可直接重新验证。修复点击第 201 项等后排结果的「重试」却再次重试前 200 项的问题，现在只重试你点击的条目。当前单个使用范围的订阅上限仍为 200 个。
- **日摘要自己选范围**：支持当前源或全部订阅的日期预览，提供「清空勾选」后自选；超限时明确提示，不悄悄截掉文章。每次最多 30 篇、30,000 字符。
- **AI 配置更明确**：提供 DeepSeek 地址／模型快捷填入，Key 由你自行配置并绑定供应商的 HTTPS 来源（origin）；切换供应商不会复用另一供应商的 Key。AI 服务可能收费，生成前显示接收方、模型与费用提醒，无默认后台请求。
