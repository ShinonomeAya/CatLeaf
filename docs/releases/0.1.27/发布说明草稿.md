# 0.1.27 测试候选版

文章AI功能更名为「AI解读」，涵盖概览、解释段落和问本文，顶栏与长按原文菜单使用同一名称。

原文依据默认折叠成一行，展开后可查看全部来源并点击定位。短标签减少重复文字，旧缓存也直接使用新样式，不需要重新生成。新请求优先选择最少必要依据；问答和段落解释直接表达内容，避免把同一个答案再写成重点。概览仍保留重点。

最终源码通过单元、lint、Debug／Release构建；Android10完成17项相关回归、八组80张截图及40条旧缓存引用展开／收起／原文定位。Android16测试手机使用用户配置的DeepSeek，对已有真实文章完成5次手动生成：4次中间包、1次最终包。最终包仅新生成段落解释，概览读取本轮真实旧缓存；改进期间的中间包与最终包证据分开记录。

本文件是未发布草稿，版本、签名、SHA-256与验证范围见[release.json](release.json)。更多文章／机型和原完整验收仍待验证，本批定向通过不等于正式G8交付。
