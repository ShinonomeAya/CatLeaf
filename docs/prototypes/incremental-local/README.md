## 筛选与提交：32–34

![阅读筛选、添加中、验证失败](32-34-filter-add-v1.png)

日期顺序固定“全部、今天、指定日期、未知日期”；“仅未读”独立组合，“清除筛选”同时清两维。加载转圈使用独立位置，文案相对整按钮居中。登记成功与RSS验证成功分别反馈，验证失败不重复新增。
