# CatLeaf（猫页）设计规范 v1.1

2026-09-25增量：原品牌、色值、字号与间距不变；新增引导/发现/使用方式视觉见[23–34增量稿](./prototypes/incremental-local/README.md)。规范数值高于生成图像像素，静态稿不替代运行时验收。

日期：2026-09-22。状态：用户已认可首批原型的设计风格，并确认产品名称 CatLeaf（猫页）。本文件将已认可的方向转成可执行的视觉规范；后续补图沿用此规范。页面行为以 [PRD](./03-PRD.md)、[页面与状态说明](./05-页面与状态说明.md) 和接口契约为准，图片不能扩张功能范围。

## 1. 品牌与设计原则

- 英文品牌：**CatLeaf**，C 和 L 大写；中文名称：**猫页**。界面首处可显示 CatLeaf 与小号“猫页”，系统应用名使用“猫页”。正文说明可称“猫页阅读器”。
- 原工作代号 CatWeb 不再作为对外品牌；现有工作区 `F:/sokusai/CatWeb`、历史图片文件和数据格式标识不因改名自动迁移。历史提示词保留原样，记录真实生成过程。
- 风格：暖白阅读面、森林绿操作色、深色正文、宽松排版。优先内容与操作反馈，不做装饰性数据仪表盘、玻璃卡片或大面积渐变。
- Folo 提供阅读交互参考，Reeder/Unread 补充列表与排版方向，Inoreader/NewsBlur 分别提供订阅管理和简报参考；参考链接见 [原型目录](./prototypes/README.md)。原生客户端用 Compose 实现同一风格，补充 Read You/Capy/Feeder 的 Android 交互参考，不另起大型组件库或照搬第三方品牌。
- 手机外框、摄像头、外部阴影仅用于原型展示，不能画进真实 App 页面。原型中文字是示例，真实内容长度必须自适应。

## 3. 字体与层级

使用 Android 系统无衬线字体及中文回退；设计意图接近清晰的人文无衬线。首版不为视觉稿单独引入大体积字体。下表为设计逻辑尺寸，布局尺寸按 dp 理解、文字按 sp 理解；Compose 使用 dp/sp 并响应系统字体缩放；正文 WebView 将用户字号/主题映射到本地 CSS，核对缩放不重复叠加。不能用图片物理像素反推布局尺寸。

| 层级 | 字号 / 行高 | 字重 | 用途 |
| --- | --- | --- | --- |
| 根页标题 | 30 / 38 | 700 | 阅读、收藏、设置 |
| 二级页标题 | 20 / 28 | 600 | AI 设置、订阅管理等 |
| 文章主标题 | 28 / 36 | 700 | 可多行，不能因长标题整体缩字号 |
| 分区标题 | 18 / 26 | 600 | 分组、今日概览、原文来源 |
| 列表标题 | 17 / 24 | 600 | 默认两行，必要时三行 |
| 正文 | 18 / 30 | 400 | 段间 16；用户可选 16/18/20/22 |
| 表单/操作 | 16 / 24 | 400–600 | 字段和按钮 |
| 辅助/元信息 | 13 / 20 | 400 | 不再使用更小字规避布局问题 |

中英文混排保持同一基线，不强制所有标题等长。日期/计数不做装饰性大数字；日报日期可用根页标题层级。英文标题自然折行，禁止压缩字宽。

## 4. 布局与尺寸

基准画布为 412 dp 宽的 Android 竖屏；必须同时适配 360 dp。以 4 dp 为最小间距单位：常用 8、12、16、24、32。标准左右内边距 24 dp，360 dp 窄屏可用 20 dp。安全区额外计算，不吞掉正文空间。

| 元素 | 规格 |
| --- | --- |
| App bar | 内容高 56 dp，系统状态栏另计 |
| 根页底部导航 | 内容高 72 dp，系统手势区域另计；仅阅读/收藏/设置三个入口 |
| 单个图标 / 触摸区 | 图形 20–24 dp，触摸区至少 48×48 dp |
| 主按钮 / 输入框 | 最小高 48 / 56 dp；键盘弹出仍可滚动到提交按钮 |
| 普通管理行 | 最小高 72 dp；双行说明或大字体时自然增高 |
| 容器 / 图片圆角 | 常规 12 dp；缩略图 10–12 dp |
| 底部面板 | 顶角 24 dp、抓手、标题与关闭入口；内容可滚动 |
| 分隔线 | 1 dp，放在行间或分区边缘，不围住每块内容 |
| 缩略图 | 列表统一 1:1；文章图可保持原比例，原型示例为 16:9 |

同一页尽量只有一个强调主操作；危险动作单独放在页面底部。列表不用多层卡片套叠，表单用标签加输入框，统计以简单文本表达。图片为辅助信息，缺图时文字仍保持对齐。

## 5. 组件规则

| 组件 | 正常/选中 | 失败/禁用 |
| --- | --- | --- |
| 主按钮 | 森林绿实底、白字、12 dp 圆角 | 忙碌时显示动作文字与进度且禁止重复提交；禁用仍说明原因 |
| 次要按钮 | 浅底或可见描边，绿色文字 | 不与主按钮争夺同等视觉权重 |
| 筛选/分段控件 | 选中用浅绿底、深绿字；未选中用正文色 | 同时保留文字状态，不能仅靠颜色 |
| 复选框 | 24 dp 图形放在 48 dp 触摸区，勾选有对勾 | 无效/重复条目不能勾选并显示原因 |
| 输入字段 | 固定可见标签、示例占位、必要辅助说明 | 错误在字段下方；不清空输入；密钥默认掩码 |
| 文章行 | 标题+摘要+元信息，缩略图靠右 | 已读通过文字/标记区分，不把整行降到无法阅读 |
| 收藏状态 | 成功写盘后图标实心；说明文本已存或仅书签 | 保存失败保留上次状态并提供重试 |
| 通知条 | 浅底、状态图标、短说明、可选单一动作 | 不盖住正文和底部操作；不把错误做成无法关闭的全屏阻断 |
| 来源引用 | 绿色编号、可读来源标题、跳转指示；单篇AI解读按§12默认折叠依据 | 无效来源不生成链接，标记结果不完整 |
| 对话框 | 明确动作标题、影响说明、取消与确认 | 删除/重置说明数据范围；不默认聚焦危险确认 |

图标保持既有 Lucide SVG 的线宽与圆角；原生客户端按需转 VectorDrawable/Compose ImageVector，保留许可。React 组件名只作语义对照，不加入另一套风格不同的图标库。选中允许实心，未选中线形；禁止将品牌猫图标塞到每一行。首次连接和空态可使用小型叶片/书页图形，避免大幅插画挤占表单。

## 6. 页面与状态的一致性

- 根页显示底部导航；详情、表单、日报、导入恢复等二级页面显示返回，不重复根页导航。面板覆盖原页面，关闭后保留其位置。
- 成功文案只表示真实完成。网络成功、本地写盘失败时不能写“已保存”；AI 任务失败不能清空原文或旧结果。
- 离线显示缓存及最后成功时间，网络动作禁用并说明；无缓存时提供连接或重试，不制造占位假文章。
- 日报先范围预览，再生成结果；重新生成可能计费，需提示。首版不在界面加入自动日程、消息通知或跨源推荐入口。
- OPML/恢复预览显示总数、可处理数、跳过/无效原因；结果页区分已完成与失败，局部成功不能被一个总成功图标掩盖。
- 空态、忙碌、失败、部分失败都沿用同一排版/颜色规则；无需为每个网络错误另造全新页面模板。
- 动效默认 150–220 ms 的淡入/面板位移；减少动态效果时关闭非必要动画。不要仅为复刻原型引入动画库。

## 7. 原型与实施验收

原型文件目录：[完整页面索引](./prototypes/README.md)。所有新增图片以已认可首屏为视觉参考，独立生成清晰页面；原始图保留，改版用 v2 等新文件名，不覆盖历史证据。

实施前读取本规范和当前任务对应原型；优先实现内容顺序、层级和交互，不硬编码示例文案、模型名、订阅数、设备外壳或图片中的时间。出现冲突时：功能/安全遵循 PRD 与接口契约，视觉尺寸遵循本规范，原型作为布局参考；记录修正，不自行重做风格。

T14 负责落地共享排版、颜色、导航与控件样式；各业务任务使用同一套规范。T22 验收 360 dp、大字号、深浅主题、TalkBack、真实数据长文本，并与对应原型对照。图片评审通过不等于这些运行验证通过。

独立品牌、平台图标、UI图标映射与空态插画已形成 [SVG素材包v2](./assets/README.md)，共52个生产用途SVG。品牌按用户提供的圆脸猫参考重绘，用户已确认采用A“歪头小叶猫”：宽圆脸、短耳、点状眼睛、透明笑嘴、7度歪头及独立实心小叶子，颜色继续遵循本规范。B眨眼、C摇尾仅保留历史，不用于正式界面。品牌视觉已定稿；旧 T02 已完成平台资源转换与模拟器检查，新原生工程 N01 核对复用，用户真机仍待 T22/T24。05、18、20使用素材索引的替换关系；原型整页PNG不作为生产切片来源。

## 8. 原生路线实施补充

依据 [ADR 002](./decisions/002-Android原生客户端.md)，本规范视觉数值和22张原型不变。N01 建最小 Compose 主题，业务页面沿用，T14 收口导航/控件。Material 组件可作基础，但关闭会改变品牌色的默认动态配色；不把整套界面换成默认 Material 模板。

布局尺寸用 dp、文字用 sp；正文 CSS 使用同一色值/字号/行距并检查系统缩放、长表格、代码、图片与文字选择。交互包括稳定列表位置、系统返回、手势、安全区、键盘、TalkBack。操作图标应有语义标签，纯装饰猫标不重复朗读；48 dp 触摸区不随图标描边大小缩水。

原 SVG 中 currentColor 在原生中映射为主题 tint；品牌多色/透明开口保持原形。旋转、evenodd、描边和透明性按源文件核对，不将 SVG 路径粗略简化。已有 android/ 平台矢量可作为 N01 输入，UI 图标转换按页面实际需要完成，不强制预生成全部空壳资源。

## 9. 本机优先与发现目录增量组件

- 加载按钮：文本相对按钮全宽居中，左右对称预留进度图形/间距，加载只占左槽，不使文字横移；文字增长可增高，禁用/进行中色映射使用匹配背景的内容色。阶段说明放按钮下，TalkBack报告进行中但不逐帧朗读。
- 筛选：阅读首页按2026-10-09用户选定C稿改为日期选择标签＋独立仅未读标签，自然换行，均至少48dp触摸区；四个日期选项在底部面板按既有顺序显示。下方结果数与次要清除操作分开，去除仅未读的大卡片和重复日期说明。日期/未读仍可组合，搜索多开关保持原分组。
- 日期范围面板沿用选择订阅面板：侧边24dp、标题区至少48dp；选项行至少56dp，内边距12/10dp，左侧36dp图标块、文字与右侧20dp勾选；选中行用现有淡绿底与12dp圆角，不显示独立圆形单选控件。保留单选语义，短屏时仅选项区滚动。
- 发现：单列列表，源图标32dp中性字标，触摸区48dp；名称最多两行自然布局，简述最多两行，元信息至少13sp；添加/已订阅状态固定右侧空间，大字可落到下一行。禁止照片肖像/仿造站标作为默认素材。
- 分类面板：两列流式选项，长词/大字可变单列；可滚动，底部避手势区；12类不强行压成两行。所有分类配文案，不只emoji。没有网格/列表双布局按钮。
- 引导：只展示一项主操作，跳过清晰；首选五源初始空复选框。装饰猫标/空态使用已交付SVG，图片中的相似图形不是新素材文件。
- 使用方式/迁移：显式当前范围和来源→目标文本；警告与保存失败用文字说明。多个统计只用辅助字体，不做巨大数字；密钥永远掩码。
- 23–34保持深浅主题映射；34为深色失败示例，其余为浅色主状态，所有页面仍须两主题/360dp/1.3字号/键盘/TalkBack实测。

## 10. 文章搜索与离线状态组件

35–40延续暖白/森林绿和既有线性图标。搜索字段使用原表单圆角，命中词以淡绿背景/适度加重突出，不改变片段行高；结果标题最多两行、纯文本片段最多三行，命中位置以辅助标签说明。筛选与正文开关分层，48dp触摸区，大字体可换行。

离线状态至少文字+图标，不只靠绿色。图片未齐用警告色，失败用错误色，进行中用确定图片计数；不能把完成3/5画成成功。容量数值用于说明，不做大数字装饰。保存按钮沿现有对称槽位加载规则，文案不位移；移除为次级危险菜单，不与收藏混用图标。

所有页面深浅/360dp/1.3字体/键盘/读屏均要验证，生成图中的演示数量、状态栏和细微字形不进入生产。图40预算需同时显示全部范围与当前范围，以PRD为准。

## 11. 根页头部与收藏空态局部修订（2026-09-30确认）

阅读/收藏/设置统一采用下列头部。它覆盖旧07图「设置→CatLeaf」的顺序，保留原01/06的品牌在上、标题在下；不要求重画全部40状态。该表为局部布局稿，数值高于旧PNG像素。

| 项目 | 三页统一规格 |

| 系统区域 | 复用RootScaffold共同安全区，不在单页重复加safeDrawingPadding |

| 验收姿态 | 三页都在滚动顶部，同机同配置比对品牌/标题起点与基线；空态/动作增减也保持坐标 |

收藏空态复用[已有empty-reading浅/深SVG](./assets/README.md)，等比约144dp、无内容说明重复朗读；插画→24dp间距→标题18/26→8dp→说明16/24→24dp→去阅读主按钮。整组在头部和底栏之间居中，长文/大字自然增高并可滚动。错误态与零收藏分开，按钮沿现有主操作规格；不另画猫标或切整页PNG。
