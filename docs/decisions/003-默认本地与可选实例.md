# ADR 003：默认本地使用，自有实例可选

日期：2026-09-25。状态：**用户已确认，设计与契约生效；应用实现待验收。** 依据[评估](../13-新增体验反馈与本地模式评估.md)及用户“确认，你开始增量原型、并更新PRD和实施计划”。本次授权交付设计/文档，不修改业务源码。

## 决策

1. Kotlin/Compose、Room、DataStore、Keystore、受控WebView与既有Cloudflare后端不换。新装默认本机，无实例/AI也能订阅、阅读、收藏、导入导出。
2. 新装两步可跳过引导；少数派、爱范儿、IT之家、阮一峰、The Verge为五个固定首选，初始不勾选。完整发现库基于340条源库快照全量核验、分类，合格项全部收录；不是自动订阅全部。
3. 自有实例成为设置中的可选使用方式。本机与每个实例分开保留数据，一次只有一个活动范围；切换不是自动同步。老用户升级保留原实例和全部数据，不重复首次引导。
4. 提供从当前实例已下载数据复制到本机的预览/确认；原数据保留。向实例转入订阅/阅读状态复用OPML/状态恢复预览，不建立双向同步。
5. AI配置独立于是否连接实例；只在用户主动请求时调用。保持原输入限额、缓存键、安全与费用边界。
6. 目录分类与个人分组分离；本地搜索只覆盖源目录。日期范围与仅未读是两个维度；添加按钮不跳动，结果如实区分登记/验证。

## 对既有约定的覆盖

ADR 002中的原生技术路线继续有效，首启必须实例、所有订阅以服务端为权威的条件改为仅实例模式适用。PRD v3、契约v3定义具体规则；历史记录不改成新模式已完成。不能用旧G1–G6通过记录代替新模式验收。G7/G8保持未通过，新增L01–L09详见任务计划。

## 不扩张的范围

2026-09-25后续批准例外：PRD v3.1新增文章搜索与单篇主动图文离线，下段“图片离线包不做”的原边界仅保留为初次决策记录；当前按契约§9与Q01–Q04。批量/自动后台下载、跨设备同步仍不做。

不做后台全天候抓取、跨设备收藏/已读同步、公共代理、目录运营后台、新AI协议、图片离线包或新根导航栏目。推荐目录数量与每个使用范围最多200个已订阅源是不同概念；普通缓存仍为2,000篇/100MiB，既定性能和无障碍标准不降。

## 实例收益与约束

可使用服务端目录、服务器RSS抓取、受限全文兜底、已有历史快照。当前原生历史写入链仍需核实/补齐原有契约，不能宣传自动完整归档、永久云备份或跨设备状态同步。实例连接失败不阻断本机使用，不删除旧范围。

## 验证与回退

新装无实例闭环、老用户原实例升级保留、切范围迟到请求归属、复制失败事务回滚、状态文件v1兼容/v2本机、目录分类去重、五源引导幂等必须新增真实证据。失败通过增量修复/兼容迁移处理，不能删库或卸载用户包；正式回退包必须兼容新schema，否则保留数据并向前修复。
