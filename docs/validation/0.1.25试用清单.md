# CatLeaf AI阅读候选版试用清单（0.1.28续修适用）

本轮希望确认OPML导入是否更容易处理，以及AI解读是否有助于理解原文。请邀请3–5位自愿试用者各自完成一次；不要把自动测试算作用户试用。本文件不代表已经完成外部验收。

1. 保留原数据安装同签名候选APK，记录App版本、Android版本及字体大小。
2. 导入自己常用工具导出的OPML；记录导出工具、条目数、成功/已保存未验证/跳过/待处理数量、操作步骤与耗时。超过200条继续下一批；验证失败时尝试重试，确认没有重复订阅。
3. 打开一篇有正文的文章，点顶栏书页星光图标进入AI解读；检查空态半屏、快速上划和键盘，再选择概览，展开依据并核对能否回到对应原文。
4. 长按原文中的文字，点系统菜单「AI解读」，检查所选文字和解释／问本文入口；歧义或跨段选文按提示改用段落列表。再问一个原文能回答的问题和一个原文没有提供的信息，评价引用与背景说明。
5. 返回概览、关闭重开，确认缓存没有重复请求；切换文章或获取全文后不混入旧结果。
6. 在全部订阅选择日期，明确勾选不超过30篇/30000字符；生成日摘要，观察同一事件是否合并、来源是否齐全。

AI仅在主动点击时请求，接收方和模型显示在界面。试用者使用自己的供应商配置并决定是否请求；不要在反馈中粘贴API Key、私人正文或含令牌的地址。
