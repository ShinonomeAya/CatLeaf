# 段落双语翻译实施计划

日期：2026-10-10。当前状态：用户确认后已实施 BT01–BT04，BT05 完成定向隔离验收与保数据安装，真实供应商及真机双语结果待验证。下文调研记录保留实施前基线；实施结果见文末，不调用收费 AI。

## 目标与界面

用户要求保留底部「翻译」按钮，在同一篇文章的对应原文下显示译文。建议成功后默认「双语对照」；顶部现有「原文 / 简体中文」改为「原文 / 双语对照」，切换只控制显示，不重新请求。保留缓存状态和手动「重新翻译」及费用说明；窄屏状态与动作允许分行，避免再次挤成竖条。

```text
原文段落 A，原有链接与强调保持。
中文译文 A

[原有图片与图注，位置和数量保持]

原文段落 B。
中文译文 B
```

译文与原文同一列，不做左右分栏。译文采用暖白/森林绿体系内的轻量区分，例如细左线与适度间距，字号随 Aa 设置、深浅主题保持对比；不在每段重复「AI 译文」标签。文章标题、元信息、封面仍出现一次，首次实施未包含标题；用户追加后，标题按独立编号与正文合并在一次请求中，原文标题下面显示标题译文。对应原型：02 文章详情的局部增量、16 阅读偏好；21 离线状态与36–40离线流程做关联回归。旧原型 PNG 保留历史，不冒称已更新。

## 核查与来源

- `ReaderScreen.kt` 当前在原文 `ArticleBodyView` 与整篇译文 Compose `Text` 之间切换；没有另开 Activity，但替换了正文容器，图片、链接与原文结构无法一起显示。
- `ReaderViewModel.kt` 以 `currentPlainText` 发起请求，译文为单个 String；已经有文章、范围、正文 revision 归属校验和全文指纹失配清理，必须保留。
- `Translator.kt` 使用 v1 prompt、整篇纯文本返回与完整结果缓存。只靠返回的换行不能可靠地对应原文 DOM 段落。
- `ArticleBodyView.kt` 已提供静态本地 HTML、受控图片与离线资源；JavaScript 关闭。正文参数变化会重载页面，`ScrollAnchor.kt` 现有读位恢复按高度比例计算，不能声称它能精确定位原文段落。
- [沉浸式翻译使用文档](https://immersivetranslate.com/en/docs/usage/)介绍双语显示与原文切换；[官方 AI Prompt 配置](https://immersivetranslate.com/en/docs/prompts/)说明多段输入及带 id/text 的结构化对应方式。借鉴交互和对应方法，不依赖浏览器扩展或其服务。官方示例使用 YAML，猫页建议复用现有 JSON 能力。

## 最小实现方式

1. **从净化后的原文建立文本块清单。** 复用 jsoup，按 DOM 顺序识别正文段落、章节标题、列表项、引用、真实图注、表格文本单元及裸文本/br 分段。嵌套父子块不重复提取；混合图片/子块保留顺序。代码块和图片不送翻译，行内代码保留。每块具有本次正文内唯一编号，重复文字也不能共用编号。先用真实 RSS/提取全文夹具验证；纯摘要无 HTML 时按可确认的文本段落构造相同输入。
2. **仍然一次手动 AI 请求。** 将多块文本连同编号一次发送，要求返回结构化对应结果，保留整篇上下文。例：输入 `[{"id":"b0001","text":"Original paragraph"}]`，返回 `{"segments":[{"id":"b0001","text":"中文译文"}]}`。保留当前 20,000 字符上限和不静默截断；结构开销、供应商长度截断按实际结果校验。不逐段收费、不自动重试、不扩展长文批量翻译或流式翻译，也不要求所有兼容供应商支持 JSON mode。
3. **严格对应后再显示。** 检查 JSON 类型、编号唯一性、缺段/多段/空译文和截断；返回顺序变化按编号归位，不能按段数或换行硬拼。不完整/格式错误明确提示，本次不写完整缓存，不覆盖先前完整译文。译文当作纯文本转义插入，模型返回的 HTML、脚本与 URL 不作为可执行内容。
4. **同一个阅读容器渲染。** 在原文净化完成后，用本地受控模板在对应块后追加译文；不放宽正文 allowlist。原文与双语都走现有 WebView，保留图片、图注、链接、代码、封面和离线资源规则；不启用 JS 或桥接。生成完成后一次更新，避免逐段刷新与多次图片回源；是否仍发生图片请求须实际抓取证据，不预先承诺零请求。
5. **缓存和状态兼容。** 复用 `AiCacheEntity.result` 保存版本化结构结果，无 Room schema 变化。缓存身份保留范围/文章、原文指纹、模型/端点/语言，并加入分块规则版本与有序文本块指纹；新 promptVersion 与旧 v1 隔离。旧缓存保留，可明确标为旧版整篇译文继续查看；只有用户主动重新翻译才生成双语，不能自动收费或猜测段落。原文仍是字数、全文、搜索、离线保存和下次请求的依据，追加译文不回写原文。切换文章/范围、获取全文、返回及旧在途结果归属保护沿用 RF03。
