### 一定会踩的坑（都踩过了）

1. **跑 `:app:connectedDebugAndroidTest` 会卸载应用并清空数据** → 之后做设备界面验证前，
   必须先跑一次实例恢复探针：
   ```bash
   adb install -r app/build/outputs/apk/debug/app-debug.apk
   adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
   adb shell am instrument -w \
     -e class 'dev.local.catleaf.nativeapp.data.network.InstanceLiveProbeTest#real_instance' \
     -e origin "https://catleaf.pages.dev" -e secret "$ADMIN_SECRET" \
     dev.local.catleaf.nativeapp.test/androidx.test.runner.AndroidJUnitRunner
   ```
   1a. **探针只恢复实例，不恢复 AI 配置**（T17 实际踩到：交接写"AI 已填好"，跑完 connected tests 后
   `ai_base_url`/`ai_model`/`ai_key.bin` 全空）。涉及 AI 的验证要**在应用内重填**：设置 → AI 配置 →
   三个字段（`adb input`，变量名 `DEEPSEEK_BASE_URL`/`DEEPSEEK_MODEL`/`DEEPSEEK_API_KEY`）→ 测试连接 → 保存配置。
2. **模拟器反复切飞行模式后 DNS 会失效**（`cmd connectivity` 显示已联网但解析不了域名）→ 重启模拟器。
   断网要用 `adb shell cmd connectivity airplane-mode enable`，`settings put global airplane_mode_on` 在模拟器上不真正断网。
3. **改源码不要用脚本整文件读写**：`io.open(p,'w').write(io.open(p).read())` 会先截断再读，把文件写成空。
   用编辑工具改；必须用脚本时先读后写分两步。含引号的 Kotlin/JS 字符串也别用 shell heredoc（会被吃字符）。
4. `adb push` 到设备要写 `//sdcard/Downloads/x`（双斜杠），否则 Git Bash 会转成 Windows 路径。
5. 本环境 `grep -r` **不搜隐藏文件**：凭据泄漏核查要用 `find -exec grep` 或 `git grep`，别信"递归 grep 无命中"。
6. 原作者的 `.gitignore` 有过未锚定的 `data/` 规则（已修为 `/data/`），会静默忽略 Kotlin 的 `data/` 包。
7. **本机 workerd 启动即崩溃**（连手写最小配置的 `workerd serve` 都 `std::terminate()`）→
   `npm run preview:cf` / `wrangler dev` 不可用；后端验证只能对**已部署实例**做。
8. **MockWebServer 的 `url()` 用本机主机名**：这台机器解析成 `steamuserimages-a.akamaihd.net:端口`
   （T12 调试时一度以为提取库把图片改指了第三方 CDN）。看到陌生 CDN 域名先 `println(server.url("/"))` 认清它。
9. **主线程网络 I/O 会崩**：`NetworkOnMainThreadException` 在 JVM 单测里永远测不出来，
   新增任何阻塞调用（OkHttp/Room 之外的 IO）都要确认调用方不在主线程——T12 的点「获取全文」就栽在这里。
10. 新版 jsoup（1.21+）默认用 HTML5 解析器：`<source>`/`<picture>` 这类元素的行为与旧版不同（T12 踩过 `picture` 被连内容删除）。
    WebView 相关代码只能在主线程调用（包括**读** `settings`），设备用例里要先在主线程取值再断言。

## 四、必须遵守的既定决策（别重新讨论）

- **客户端**：Kotlin + Compose，单 `app` 模块，包名 `dev.local.catleaf.nativeapp`，minSdk 29。
  版本锁定 AGP 8.13.2 / Gradle 8.14.3 / Kotlin **2.3.20**（KSP 只到 2.3.20，Room 需要它；升 Kotlin 前先确认 KSP）/ Compose BOM **2026.03.01**
  （更高的 BOM 要求 AGP 9.1 + compileSdk 37）。见 `android-native/gradle/libs.versions.toml`。
- **后端**：继续二开原项目（MIT，Copyright (c) 2025 su-kaka）；不换平台、不复用他人资源 ID。
- **grep/身份**：`guid` 与 `link` **保持独立**（不要照搬 React 参考实现里 guid 回退成 link 的写法）。
- **净化**：所有正文走同一 allowlist 入口（T12 已落地为 `ArticleSanitizer`）；WebView 不开 JS、不加原生桥；外链走系统浏览器。
- **凭据**：只在 Keystore 加密的私有密文文件与内存里；不进源码/日志/Room/DataStore/URL/导出。
- **数据**：合并保留已读收藏（整行 upsert 前必须先读回旧行带状态）；合并器**不含删除操作**，抓取失败无法清空本地。
- **正文来源**：只有 `content:encoded/content` 算正文，摘要留在 `description`（T12 修正了 T10 的“摘要当正文”回退）；
  `contentSource` 词汇表集中在 `ArticleMerger`（rss/extracted/summary）。
- **公开抓取**：`PublicFetch` 是阻塞式且**只**用于公开资源（无凭据、仅 HTTPS、逐跳校验、有上限）；调用方负责不在主线程调用。
- **规范**：视觉尺寸按 `docs/07-设计规范.md`；原型只是布局参考；**二级页整屏、不重复根页导航**；内容必须避让系统栏。
